Управление

🕹 Левая половина — джойстик движения. Появляется под пальцем.

⚽ Удар — держи для накопления силы, тяни в сторону для скручивания.

➤ Пас — мягкий удар, удобен для передачи.

⚡ Рывок — короткое ускорение (кулдаун 2.5с).

🎯 Отбор — отбирает мяч у соперника и замедляет его (кулдаун 3с).

Правила

🧲 Магнит работает автоматически — мяч всегда тянется к ближайшему игроку в радиусе 240.

🥅 Забей больше голов, чем соперник. За каждый гол — монеты для магазина.

🔥 Комбо — 2 гола подряд = Дубль, 3 = Хет-трик, 4+ = ОГОНЬ!
